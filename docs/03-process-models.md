# 03. Модели процессов

В данном разделе представлены модели ключевых бизнес-процессов и сценарии взаимодействия микросервиса «Копилка» со смежными системами Банка.

---

## 1. Процесс подключения сервиса «Копилка» (BPMN / Flowchart)

Данный процесс описывает пользовательский сценарий создания Копилки в Мобильном приложении, включая бизнес-валидацию на стороне микросервиса и открытие счета в банковском ядре (Core Banking / АБС).

### Диаграмма процесса

```mermaid
graph TB
    subgraph Client_Lane ["👤 Клиент (Mobile App)"]
        A([Старт: Нажал 'Включить Копилку'])
        C1[Выбрать шаг округления]
        C2{Решение пользователя}
        E1[Просмотр ошибки: 'Копилка уже существует']
        E2[Просмотр экрана: 'Копилка успешно создана!']
        
        End_Cancel([Конец: Отменено пользователем])
        End_Error([Конец: Ошибка подключения])
        End_Success([Конец: Сервис подключен])
    end

    subgraph Piggy_Lane ["🐷 Микросервис «Копилка»"]
        B{Есть активная Копилка?}
        D1[Запрос в АБС на создание накопительного счета]
        D3[Сохранение настроек в БД (Status = ACTIVE)]
        F1[Формирование Push-уведомления]
    end

    subgraph ABS_Lane ["🏦 Core Banking (АБС / Bank Core)"]
        D2[Создание накопительного счета & Выдача Account_ID]
    end

    %% Поток управления
    A --> B
    
    %% Альтернативный сценарий: Дубликат
    B -- Да (422 Error) --> E1
    E1 --> End_Error
    
    %% Основной сценарий
    B -- Нет --> C1
    C1 --> C2
    
    C2 -- Нажата 'Отмена' --> End_Cancel
    C2 -- Выбран шаг (10/50/100/500 ₽) --> D1
    
    D1 --> D2
    D2 --> D3
    D3 --> F1
    F1 --> E2
    E2 --> End_Success
