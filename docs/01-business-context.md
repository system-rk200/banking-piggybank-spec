# 01. Бизнес-контекст и границы проекта

## 1. Глоссарий терминов

| Термин / Сокращение | Описание |
| :--- | :--- |
| **Сервис «Копилка»** | Микросервис автонакоплений, сберегательный продукт банка. |
| **Правило округления** | Алгоритм, определяющий сумму, которая списывается с основного счета и зачисляется на счет Копилки при совершении покупки. |
| **Шаг округления** | Кратность суммы (10, 50, 100, 500 ₽), до которой округляется сумма транзакции. |
| **Счет списания** | Дебетовый счет Клиента, с которого происходит покупка и списание сдачи. |
| **Счет Копилки** | Накопительный счет Клиента, куда зачисляется сдача с округлений. |
| **АБС / Core Banking** | Автоматизированная банковская система, ведающая счетами и проводками. |

---

## 2. Бизнес-цели и ценность продукта

### Проблема
Клиентам тяжело копить деньги систематически — откладывать фиксированные суммы вручную требует дисциплины и вызывает психологический комфортный барьер.

### Решение
Автоматические фоновые накопления без явного участия клиента по модели *«копим незаметно при каждой покупке»*. Сдача от округления суммы чекa автоматически переводится на накопительный счет.

### Бизнес-метрики (KPI)
* **Рост пассивов:** Увеличение объемов остатков на накопительных счетах физлиц.
* **Вовлеченность (Engagement):** Увеличение безналичной транзакционной активности по дебетовым картам.
* **LTV & Retention:** Повышение пожизненной ценности клиента за счет использования экосистемы продуктов банка.

## 3. Целевая аудитория

* **Целевой пользователь:** Физическое лицо, активный держатель дебетовой карты банка, пользователь Мобильного приложения.
* **Cценарий использования:** Клиент единоразово подключает сервис в Мобильном банке, выбирает удобный шаг округления (например, 100 ₽) и далее накапливает средства в фоновом режиме.

---

## 4. Границы проекта (Scope)

### ✅ Входит в рамки релиза v1.0 (In Scope)
* Подключение, настройка и отключение сервиса «Копилка» через Мобильное приложение.
* Выбор и изменение шага округления (10, 50, 100, 500 ₽).
* Автоматический расчет округления при обработке транзакций типа `POS / E-com Payment`.
* Инициирование перевода сдачи с дебетовой карты на счет Копилки.
* Просмотр баланса и истории накоплений.
* Отправка Push-уведомлений о зачислении средств.

### ❌ НЕ входит в рамки релиза v1.0 (Out of Scope)
* Начисление процентов на остаток по счету (выполняется модулем АБС).
* Автоматическое инвестирование накоплений в ценные бумаги.
* Совместные копилки для нескольких пользователей.
* Округление транзакций P2P-переводов и снятия наличных в банкоматах.

---

## 5. Взаимодействующие системы

* **Mobile App (ДБО):** Клиентский интерфейс для управления настройками и просмотра баланса.
* **Processing Center:** Поставщик событий об успешных авторизациях/транзакциях по картам.
* **Core Banking (АБС):** Исполнитель межсчетных переводов и хранитель балансов.
* **Notification Service:** Сервис отправки Push/SMS клиенту.

---

!!! note "Бизнес-допущение (Assumption)"
    В рамках релизной версии **v1.0** предполагается, что у пользователя может быть открыта только **одна активная Копилка**, привязанная к единому дебетовому счету.
